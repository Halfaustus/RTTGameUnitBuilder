# RTTGameUnitBuilder

版本：V1.0。面向独立游戏 RTT 的 Windows 单位创建与配置编辑器，使用 C#、Windows Forms 和系统 .NET Framework。项目独立于游戏运行工程，启动时不内置正式单位模板。

## 功能概览

支持单位基体、武器、共享弹药、武器配装及单位配置的创建和编辑；维护稳定引用、配置关系、库存归属和能力来源，并提供复制、删除保护、字段校验、草稿保存与重载。GUI 与程序化调用共用创建核心、领域模型、校验器和序列化规则。

五个工作页面分别处理单位基体、武器、共享弹药、武器分配和单位配置。界面提供完整名称显示、可滚动的配置明细及独立校验反馈区域。

## 构建与使用

在 Windows 项目根目录运行 Build.cmd，随后启动 bin/RTTUnitEditor.exe。

需要系统安装 .NET Framework 4.x，并具有系统 C# 编译器。构建脚本使用 Framework64 下的编译器，无需第三方运行库。构建前请关闭正在运行的编辑器。

建议按“基体 → 武器／弹药 → 配装 → 单位配置”的顺序组织数据。可保存未完成草稿；保存成功不表示完整合法，也不表示可直接用于游戏。修改后应重新校验。

## 项目结构

- src/：界面及核心；Domain 为领域模型与规则，Editing 为共享创建核心，Storage 为持久化，Legacy 为旧格式兼容。
- Build.cmd：标准构建入口；生成的 bin/ 不纳入 Git。
- DESIGN_BASELINE.md、design/：当前本地设计基线及规范正文。
- docs/RTT_GAME_DATA.xlsx：项目作者原创正式参数。
- docs/BASELINE_SOURCES.json：本地规范及数据来源记录。
- PROJECT_STATUS.md：当前能力和未决事项。
- AGENTS.md：项目职责、开发及资料使用约束。

## V1.0 状态与边界

当前本地设计基线为 DB-2026-10-06-40，业务代码仍保留 DB33 来源标识。现有 v5 文件支持保存、重载与兼容读取，但尚未完成 DB40 正式定义交付认证；非直射弹药初速表达、默认弹药共享校验及部分能力资格仍有缺口。新建定义保留 TestOnly 标记。

V1.0 是当前编辑器的版本记录，不是完整游戏规则认证。游戏运行、战斗计算、战斗群组建、三维、外部数据导入和游戏侧集成不属于本编辑器已实现能力。具体限制见 [当前状态](PROJECT_STATUS.md)。
